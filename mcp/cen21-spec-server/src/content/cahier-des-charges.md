# Cahier des charges — Cen21 Hospitality

## 1. Présentation générale

**Nom du projet :** Cen21 Hospitality — Plateforme Digitale Premium

Cen21 Hospitality est une holding spécialisée dans l'hospitalité, le divertissement et les expériences lifestyle haut de gamme. Le groupe regroupe actuellement **huit (8) filiales** : restaurants, bars, lounges, boîtes de nuit, espaces événementiels premium.

## 2. Contexte

Mise en place d'une plateforme digitale moderne pour renforcer l'image de marque, présenter les filiales, créer une expérience immersive premium, centraliser la communication digitale et préparer des fonctionnalités transactionnelles futures. Identité : luxueuse, sophistiquée, cinématographique.

## 3. Objectifs

- Valoriser l'image premium du groupe
- Présenter les filiales et promouvoir événements / expériences
- Navigation immersive et moderne
- Préparer l'intégration d'un système de réservation

## 4. Architecture

- Plateforme principale (holding)
- Huit (8) espaces dédiés aux filiales
- Par filiale : page dédiée, identité visuelle, galerie, infos pratiques, description, événements associés

**Note :** La section 8.1 mentionne une liste de **dix (10) établissements** sur la page Filiales — à aligner avec le métier.

## 5. Direction artistique

Luxe moderne, élégance minimaliste, immersion, profondeur cinématographique, expérience éditoriale premium. Inspirations : hôtels de luxe, magazines mode, architecture contemporaine, nightlife haut de gamme.

Navigation fluide, immersion visuelle, intuitivité, hiérarchie claire, cohérence entre filiales. Responsive : desktop, tablette, mobile.

## 8. Fonctionnalités V1

### Pages principales

- **Accueil** — immersion, groupe, highlights filiales, CTA
- **À propos** — histoire, vision, valeurs, positionnement
- **Filiales** — liste des établissements (10 mentionnés en 8.1), navigation vers espaces dédiés
- **Événements** — soirées et activités
- **Galerie** — photos HD, vidéos immersives
- **Contact** — formulaire, coordonnées, réseaux sociaux

### Gestion de contenu

Modification contenus, images, actualités, événements, infos établissements. Administration : pages, médias, filiales, événements, contenus.

## 9. Fonctionnalités V2

Réservation : table, VIP, établissement, date, horaire, confirmation, consultation réservations. Admin : réservations, disponibilités, capacités, horaires, statistiques. Architecture V1 pensée pour intégration facile.

## 10. Médias

Haute résolution, professionnels, luxe, optimisés web. Types : photos, vidéos, animations, visuels promotionnels.

## 11. Contraintes techniques

## 13. SEO

Référencement naturel, performances Google, métadonnées, réseaux sociaux.

## 14. Administration

Tableau de bord : pages, médias, filiales, événements, contenus.
